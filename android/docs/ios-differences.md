# ToriWords Android — differences from iOS

The Android app does everything the iOS app on `main` does, with the same features, screens and wording (see [product.md](product.md), [ui.md](ui.md), [copy.md](copy.md)). This file lists every deliberate difference and the reason for it. Anything not listed here works as on iOS.

| Difference | iOS | Android | Reason |
|---|---|---|---|
| Sync service | iCloud. Sync is on automatically when the user is signed in to iCloud, and is turned off in iOS Settings. | Google Drive, in the app's hidden Drive folder. Off by default. The user turns it on in Settings → Google Drive sync, which shows the system Google account picker and consent. Turning it off and "Delete Drive data…" are both in the app. See [sync.md](sync.md). | Android has no account-level sync that apps can use without asking. There is no own backend and no app account. An explicit turn-on is needed for Drive access. |
| Phones without Google Play services | Not applicable. | Google Drive sync and on-device translation show "Not available on this device". A word that has no dictionary hit goes straight to "No translation found — add your own". The rest of the app works fully. | Drive access and the translation model need Google Play services; the app does not ship a substitute. |
| Capture entry points | Share extension: select text → Share → ToriWords. | **ToriWords** in the text-selection menu of other apps (in some apps under the menu's ⋮), and in the share sheet. Both open the same capture sheet. See [capture-and-enrichment.md](capture-and-enrichment.md). | The selection menu is the shortest Android path from selected text, and it is where Android users look for "translate"-style actions. |
| Source of a captured word | From Safari: "Safari · <domain>" (app "Safari") with the page title, and Safari also fills in the sentence around a short selection. From other apps: the domain alone, or nothing without a link; iOS does not tell the share extension which app shared. The title is editable. | For a text selection: the source app's name when Android reports it, otherwise empty. For Share with a link: "<app> · <domain>", or the page title. Editable. | The selection menu passes only the text; Android may or may not say which app sent it. |
| Share-menu tip | "Tip: put ToriWords first", with steps to reorder the share row. | None, and no tip about the selection menu either. | Android has no single reorder step to point at, and the selection-menu position is decided by each app. |
| Capture before the first app open | Works from the first install: the share extension reads the dictionary from the app bundle, so lookups work before the first app open. "Could not save. Open ToriWords once, then try again." appears only when the App Group container is unavailable or the inbox file cannot be written. | Capture works from the first install, before the app was ever opened. | On first start, the app copies the built-in dictionary out of the install package. The capture sheet can trigger the same step. |
| On-device translation | Apple Translation. The language data is downloaded via a Download button or in iOS Settings. | Google's on-device translation model (ML Kit). It downloads by itself over Wi-Fi. States: Ready, Downloading… (no percentage), Waiting for Wi-Fi with "Download now on mobile data", Waiting for network, Download failed with Try again, Not available on this device. | Apple Translation is iOS-only. The ML Kit model is the closest offline equivalent on Android. |
| Translation diagnostics disclosure | None needed. | About → Privacy says that the translation component sends Google diagnostics about its own use, and that the translated text stays on the phone. The Google Play Data safety form declares the same. | ML Kit sends usage diagnostics to Google. The owner chose to keep ML Kit and disclose this. |
| Haptics | Haptic feedback: a launch roll of seven soft taps, the swipe detent ticks, the live-header taps (light on tap, soft on leaf fall). | The same moments and timing ([ui.md](ui.md#5-motion-and-haptics)). Phones that cannot play the launch roll get one predefined click. Mechanism: [architecture.md](architecture.md#9-haptics). | Vibration hardware varies widely between Android phones; the fallback keeps a tactile cue on every phone. |
| Header buttons and surfaces | 44 pt targets; Liquid Glass on iOS 26. | 48 dp Material 3 icon buttons. No glass or blur anywhere. | Material 3 sets 48 dp targets and has no glass material. |
| Navigation and Back | Edge swipe back; Cancel / Done in edit mode. | System Back and predictive back; edge-to-edge. Edit mode is a full-screen dialog with ✕ / Save. Back closes the topmost sheet, dialog or open row first. See [ui.md](ui.md#3-system-back-predictive-back-edge-to-edge). | Android platform conventions. |
| Undo after delete | In-app toast with Undo. | Material snackbar with Undo. | Android pattern. |
| Export | Share sheet only (Save to Files is one of its targets). | Two buttons: **Share** (share sheet) and **Save to device** (the system save-file picker, no permission). | The Android share sheet has no reliable "save to file" target. |
| Phone backup | The database is in the iCloud device backup. | Android Auto Backup backs up the user database as it is. Android caps an app's backup at 25 MB; above that, the device backup is skipped and Drive sync or export remain the backup path. | The owner accepted the cap for v1. A compact backup copy is a later idea. |
| Widget hint | Text steps only (Edit → Add Widget). | Android steps ("touch and hold an empty area, tap Widgets…") plus an **Add widget** button that asks the launcher to place the widget, where the launcher supports it. | Android lets an app request widget placement; iOS does not. |
| Widget | Home Screen and other system widget families. | A home-screen widget only, resizable between 2×1 and 2×2. | Settled v1 scope; most Android phones have no lock-screen widgets. |
| App language | Set in iOS Settings → ToriWords; the app shows "Change in iOS Settings ›". | Android 13 and later: the system per-app language screen, opened from Settings → Language. Android 12: an in-app list (System / English / Русский). | Per-app language exists in system settings only from Android 13. |
| Reminders | Delivered at the chosen time. | Delivered **around** the chosen time, usually within a few minutes, and the copy says so. As on iOS, the notification has no title of its own and the text "N to review"; the system shows "ToriWords" in its header. It belongs to the "Daily reminder" channel. On Android 13 and later, turning the reminder on asks for notification permission. | Exact alarms need a special permission that a review reminder doesn't justify. |
| Notifications blocked | Notice with "Open iOS Settings". | The switch stays on; the notice "Notifications are off for ToriWords" has **Open system settings ›**, which opens the app's notification settings. | Android wording and target screen. |
| Colours | Fixed green palette, light and dark. | The same fixed palette in light and dark, in the app and the widget. No dynamic colour (Material You). | Brand consistency; owner decision. |
| App icon | The mark at 75 % of the icon on a light background; light and dark icons only. iOS generates the tinted look. | Adaptive icon with the mark inside the safe zone (so it is relatively smaller), a dark variant, a monochrome layer for themed icons, and a monochrome notification icon. | Android launchers mask icons into different shapes and can theme them. |
| Speech voices | iOS voices; missing voice → steps in iOS Settings. | Offline voices of the phone's text-to-speech engine only. A missing English voice opens a dialog with **Install voice data**, which opens the system installer. | Online voices would break the offline promise and send words off the phone. |
| Reduce Motion | iOS Reduce Motion. | Android "Remove animations", with the same effect: finished launch mark, cross-fade flip, no swipe demo. The live header ignores it on both platforms. | Platform setting name. |
| Launch splash | Launch screen in the background colour, then the animated mark. | The system splash (background colour only, no icon), then the same animated mark and timing. | Android 12+ always shows a system splash. |
| Dictionary storage | Read from the app bundle. | Copied out of the install package on first start. | Android cannot open the packaged dictionary in place. |
